## 1. 키 바인딩 전체

키 설정 화면은 네 묶음(재지정 가능)과 고정 키 묶음으로 나뉜다. 아래 "내부 키" 열은 `index.html`의 `data-key` 속성 값이다. 재구현의 액션 ID로 그대로 쓸 수 있다. 원본 HTML에서 찾지 못한 항목은 "—"로 둔다.

| 동작 (원문) | 한국어 | 기본 키 | 내부 키 |
|---|---|---|---|
| Move Up | 위로 이동 | W | `up` |

## 2. 마우스

| 입력 | 동작 | 근거 |
|---|---|---|
| 이동 | 조준 방향. 전장 커서는 `crosshair` | 하단 안내 "Mouse Aim / Attack", CSS |
| 좌클릭 | 연속 공격(Combo). 도움말: 3단 연속 베기, 3타째 띄워 날림 | 고정 키, #help |
| 우클릭 누르기 | 기 모으기 → 강공격(Charge Up / Heavy Attack). 오래 누를수록 강함 | 고정 키, #help |
| 휠 | 확대·축소 | 고정 키 |
| 커서 위치 | V(커서 공격), X(커서 고수)의 목표 지점. 적 부대 위면 공격, 지면이면 진형을 갖춰 이동 | #orders title |
| 적 부대 호버 | 붉은 원 + `Enemy 부대명 병력` 라벨 | `research/g-14-fight2.png` |
| 유닛 카드 클릭 | 해당 유닛 선택 | CSS `.card { cursor: pointer }` |
| 전술 지도 좌클릭 | 부대 선택 | #help |
| 전술 지도 Shift+좌클릭 | 추가 선택 | #help |
| 전술 지도 우클릭 | 선택 부대에 명령 | #help |

- 원거리 무기(활/쇠뇌, 법구)를 들었을 때 좌클릭이 사격으로 바뀌는지는 미확인이다.
- 전술 지도가 아닌 일반 화면에서 우클릭이 부대 명령으로 쓰이는지는 미확인이다(일반 화면 우클릭은 기 모으기).
- 드래그 박스 선택은 관찰하지 못했다(미확인).

## 3. 숫자 키와 선택

| 입력 | 동작 |
|---|---|
| 1–9 | 해당 번호의 유닛으로 전환(카드 좌상단 번호) |
| Shift + 1–9 | 선택에 추가 |
| 0 | 내 전선으로 복귀. 도움말 "`` ` ``／0 回到本路（可接管副將）" |
| `` ` `` | 전선 선택(Select Front). HTML 원형 이름은 `全軍`(전군), 버튼 `選取全軍` |
| 선택 없음 | 명령은 내 전선 전체에 적용 |

- 유닛이 10개 이상일 때(헤이스팅스 11개) 10번 이후를 키로 고르는 방법은 미확인이다. 카드 쪽 넘김(◀ ▶) 후 클릭은 가능하다.
- 숫자 키 번호가 카드 쪽마다 바뀌는지(쪽 기준인지 전체 기준인지)는 미확인이다. 실측 카드 번호는 1~6이 첫 쪽에 있었다.

## 4. 명령 입력 흐름

명령은 "대상 고르기 → 명령 키 → (필요하면) 커서 지점" 순서다. 대상이 없으면 내 전선이 받는다.

```
대상 선택(1–9 / 카드 / 지도 / 없음=내 전선) → 진형 키(F G H [ ]) → 명령 키(C V Z X) + 커서 위치 → 실행
                                                              ↓ B
                                                          AI 위임(다시 B 또는 다른 명령 → 회수)
```

- 진형 키와 명령 키의 순서가 바뀌어도 되는지는 미확인이다. 진형 버튼은 토글이며 현재 진형은 `陣形: Block`처럼 표시된다.
- 명령을 내리면 화면 중앙 하단에 명령 문구가 잠시 뜨는 것으로 추정한다(`#banner.order`: 하단 70% 위치, 30px).

## 5. 재지정 (Rebinding)

| 규칙 | 내용 |
|---|---|
| 방법 | 동작 옆 키 버튼을 누른 뒤 새 키를 누른다. 대기 중 버튼은 붉게 깜빡인다(`.kbtn.wait`) |
| 충돌 처리 | 이미 쓰는 키를 누르면 두 동작의 키가 **자동으로 서로 바뀐다**(swap) |
| 변경 표시 | 기본값과 다른 키는 노란 테두리(`.kbtn.changed`) |
| 저장 | "이 기기의 브라우저에 저장"(localStorage로 추정, 키 이름 미확인) |
| 복원 | `Restore Defaults` |
| 닫기 | `Done` |
| 진입 | 일시정지 메뉴 `Key Bindings`. 도움말 "暫停選單可改按鍵"(일시정지 메뉴에서 키 변경 가능) |
| UI 반영 | HUD의 키 표시(스킬 칸, 명령 패널, 도움말)는 `data-key` 속성으로 현재 바인딩을 다시 그리는 것으로 추정 |
| 고정 키 | 1–9, 0, 좌·우클릭, 휠은 바꿀 수 없음 |

- 마우스 버튼이나 수정 키(Ctrl, Alt) 조합을 바인딩할 수 있는지는 미확인이다.
- Esc를 다른 키로 바꿨을 때 키 대기 상태를 Esc로 취소할 수 있는지는 미확인이다.

## 8. 재구현 체크리스트

| WASD + Shift | 이동, 질주 |
| 좌클릭 3회 | 3단 연속 공격, 3타째 띄워 날림 |
| 우클릭 누름 → 뗌 | 누른 시간에 비례한 강공격 |

| Space | 회피(무적) |
| 1–9 / Shift+1–9 / 0 / `` ` `` | 선택, 추가 선택, 내 전선 복귀, 전선 선택 |
| C V Z X | 전방 정렬, 커서 공격, 돌격, 커서 고수 |
